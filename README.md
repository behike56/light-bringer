# Light Bringer

ドメイン知識のグラフデータ化とグラフデータの可視化を行うデスクトップアプリケーション。

## macOS で起動する

Rust の安定版と Xcode Command Line Tools を用意し、リポジトリのルートで実行します。

```sh
cargo run --locked --manifest-path apps/desktop/Cargo.toml
```

「新規」で SQLite ファイルの保存先を選び、左の一覧からノードと関係を追加します。詳細フォームの「反映」でグラフを更新し、「保存」または `⌘S` でファイルに確定します。ノードをドラッグすると配置を変更できます。空白のドラッグで移動し、スクロールやピンチで拡大・縮小できます。

「JSON 書出」は最後に保存したグラフを書き出します。「JSON 取込」で既存の JSON から新しい SQLite プロジェクトを作成できます。新規プロジェクトと書き出しには新しいファイル名を指定します。
