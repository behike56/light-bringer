# Light Bringer

ドメイン知識のグラフデータ化とグラフデータの可視化を行うデスクトップアプリケーション。

## macOS で起動する

Rust の安定版と Xcode Command Line Tools を用意し、リポジトリのルートで実行します。

```sh
cargo run --locked --manifest-path apps/desktop/Cargo.toml
```

「新規」でフリーモードまたはDDDモードを選び、`.lbproj` の保存先を指定します。左の一覧からノードと関係を追加し、詳細フォームの「反映」でグラフを更新します。「保存」または `⌘S` でファイルに確定します。ノードをドラッグすると配置を変更できます。空白のドラッグで移動し、スクロールやピンチで拡大・縮小できます。

DDDモードでは7種類のカードと矢印で業務の流れを表せます。編集中のプロジェクトは、ツールバーのモード名から切り替えられます。

「開く」では `.lbproj` と既存の `.sqlite` を開けます。「別名で保存」または `⇧⌘S` で、編集中のグラフを新しい `.lbproj` に保存し、編集先を切り替えます。既存の `.sqlite` からの移行にも使えます。

「JSON 書出」は最後に保存したグラフを書き出します。「JSON 取込」は JSON から新しい `.lbproj` を作成します。新規作成、別名保存、JSON の取り込みと書き出しには新しいファイル名を指定します。
