# カードの整列機能の設計

キャンバスで選んだカードの端や中央を揃え、カード間の空白を均等にします。DDDモードでは業務フローの行や列を整えられます。フリーモードでも同じ操作でノードを整列できます。本書では両方を「カード」と呼びます。

## 1. カードの選択

カードをクリックして選び、`Shift` を押しながら別のカードをクリックして選択に加えます。まとめて選ぶ場合は、`Shift` を押しながらキャンバスの空白をドラッグします。

| 操作 | 結果 |
| --- | --- |
| カードをクリックする | そのカードを単独選択し、詳細フォームを開きます。左の一覧でも同じ操作ができます。 |
| `Shift`＋カードをクリックする | そのカードの選択を切り替えます。左の一覧でも同じ操作ができます。 |
| `Shift`＋空白をドラッグする | 枠を表示し、ドロップ時に枠に全体が入ったカードを選択に加えます。ドラッグ方向は問いません。 |
| 空白をドラッグする | 選択を保ったまま、キャンバスをパンします。 |
| カードを通常ドラッグする | そのカードを単独選択し、従来どおり1枚を移動します。 |
| 矢印や関係一覧の項目をクリックする | カードの選択を解除し、その関係の詳細フォームを開きます。 |
| キャンバスにフォーカスがあるときに `Esc` を押す | 範囲選択中は枠を取り消します。ドラッグしていないときは選択を解除します。 |

選択したカードはキャンバスと一覧で強調します。複数選択中は詳細ペインに選択枚数を表示し、1枚に戻るとそのカードの詳細フォームを表示します。関係の追加・削除を含む詳細フォームの操作は、従来どおり単独の項目を対象とします。

詳細フォームの反映前の入力があるときに、フォームを閉じる選択操作を試みた場合は、既存の「詳細フォームの入力を反映するか、取り消してください」を表示します。入力と選択を保持します。範囲選択中はパンとズームを止め、枠とカードの位置関係を固定します。枠はキャンバスの表示範囲内に収めます。モードを切り替えるときは操作中の枠を破棄し、確定済みの選択を引き継ぎます。

## 2. 整列メニュー

キャンバス上部に「整列」メニューを置きます。選択中のカードだけを対象とし、操作を選ぶとその場で配置を反映します。同じ選択のまま「上揃え」「横方向に等間隔」のように操作を続けられます。

| 操作 | 必要な枚数 | 移動の方向 |
| --- | ---: | --- |
| 左揃え、横中央揃え、右揃え | 2枚以上 | 左右に移動します。 |
| 上揃え、縦中央揃え、下揃え | 2枚以上 | 上下に移動します。 |
| 横方向に等間隔、縦方向に等間隔 | 3枚以上 | 選んだ方向のカード間の空白を均等にします。 |
| 整列を取り消す | 直前の整列を取り消せるとき | その操作で動いたカードを元の位置に戻します。 |

メニューは必要な枚数に満たない項目を無効にします。処理中やドラッグ中は整列を無効にし、実行時にも条件を確認します。整列用のボタンとメニューはキャンバスの描画領域から分け、押したときに選択やパンが始まるのを防ぎます。

## 3. 配置の計算

保存する `Position` の `x`・`y` はカードの中心座標です。計算には、選択した各カードの現在位置と、描画・クリック判定が共有する `node_half_size` を使います。現在の描画寸法はDDDモードが幅156・高さ78、フリーモードが幅156・高さ44です。左から右へ `x` が増え、上から下へ `y` が増えます。パンやズームを変えても、同じ選択から同じ配置が得られます。 [キャンバスの実装](../../apps/desktop/src/ui/canvas.rs)

### 端と中央を揃える

選択全体を囲む矩形を基準にします。左揃えでは全カードの左辺を矩形の左辺に、右揃えでは右辺を右辺に揃えます。横中央揃えでは各カードの `x` を矩形の左右の中点に揃えます。上下方向にも同じ計算を適用します。移動と直交する軸の座標はそのまま使います。

### 空白を均等にする

対象の軸の中心座標でカードを並べます。同じ座標の場合は直交軸の中心座標で並べ、それも同じ場合は UUID の昇順にします。最初と最後のカードは位置を固定します。その外端間の長さから、対象軸上のカード寸法の合計を引き、隙間の数で割ります。中間のカードをその空白幅で並べます。直交軸の座標はそのまま使います。

たとえば幅156のカード3枚の `x` が `100, 310, 600` の場合、横方向に等間隔を実行すると `100, 350, 600` になり、カードの縁から縁までの空白はどちらも94になります。

空白幅が負になる場合は「カードを等間隔に並べる幅が足りません。両端のカードを離してください」と表示し、配置を維持します。縦方向の案内では「高さ」「上下端」を使います。空白幅が0の場合は辺を接して配置します。揃えた結果としてカードが重なることは許容します。位置調整は利用者がドラッグで行えます。

## 4. 編集状態と保存

整列は変更後の座標を全件計算し、ノードの存在と座標の有限性を検証してからメモリ上のグラフへ一括適用します。計算や検証に失敗した場合はエラーを表示し、整列前の配置を保ちます。すべての移動量が既存のドラッグ判定と同じ `0.001` グラフ座標単位以下であれば、編集履歴と未保存状態を更新しません。描画は更新後の配置から矢印の経路を再計算します。

「整列を取り消す」は、最後に座標を変更した整列1回分を戻します。対象カードのIDと変更前後の座標を編集中のプロジェクトに保持します。「保存」や「別名で保存」の後も、同じグラフを編集中であれば取り消せます。対象カードをドラッグで別の位置に移した場合や削除した場合は、その取り消しを無効にします。取り消し時には現在の座標が記録した変更後の座標と一致することを確認し、座標をまとめて戻します。プロジェクトを閉じた場合やグラフを読み込み直した場合は履歴をクリアします。

位置の未保存判定には最後に保存した `Position` 群との差分を使います。保存前に整列を取り消して元の保存位置に戻れば、位置の未保存表示は消えます。フォームやグラフの内容に別の変更があれば、未保存表示は残ります。保存後に整列を取り消した配置は、次の保存でファイルに反映します。

「保存」と「別名で保存」は既存の保存経路で配置を確定します。「JSON 書出」は最後に保存した配置を使います。既存の `.lbproj`、単体 `.sqlite`、JSON のいずれも現在の `node_positions` に収まります。閉じる操作では、位置の差分も既存の未保存確認に含めます。 [プロジェクトファイル設計](project-file.md) · [プロジェクトを閉じる機能の設計](close-project.md)

## 5. 実装と検証

単独の項目を開く `Editor::selection()` は現在、詳細フォームから選択を取得します。フォームが示す単独項目と、複数選択したカードのID集合を `Editor` で管理し、選択操作は同じ入口で更新します。複数選択に入るときはフォームを閉じ、単独選択に戻るときはID集合を空にしてフォームを作り直します。整列の対象は、グラフ上に実在し、配置が確定したカードです。 [選択とフォームの実装](../../apps/desktop/src/ui/mod.rs)

| 実装箇所 | 変更内容 |
| --- | --- |
| `ui/mod.rs`・`ui/canvas.rs` | 一覧とキャンバスの選択を同期します。既存のクリック判定と座標変換を使い、範囲選択、強調表示、整列メニューを追加します。新規フォームを開くときは、既存の未反映チェックを経て複数選択を解除します。 |
| `ui` の配置計算 | カードの矩形と操作を入力とし、変更後の座標を返す純粋関数にします。パン、ズーム、矢印の内容から独立させます。 |
| `graph.rs` | `Graph::put_position` と同じ存在・有限性の検証を共用し、重複IDを含め全件を検証してから適用する一括更新を追加します。 |
| `Editor`・`ui/files.rs` | ドラッグ、整列、取り消し、ノード追加・削除で位置の差分を更新します。`has_changes` は位置、グラフ内容、フォームのいずれかの変更を拾います。読み込み時は補完前の保存位置を基準にします。「保存」「別名で保存」が成功した時点で、保存したスナップショットの位置を新しい基準にします。 |

座標の計算は入力と出力を比較し、選択から保存までは既存のGPUIテストと同じ方法で確認します。

| 確認する場面 | 期待する結果 |
| --- | --- |
| DDDモードで「注文する」「注文」「注文された」を選び、上揃えしてから横方向に等間隔にする | 上辺と空白が揃います。カードの移動は選択範囲内で完結し、同じ順序で矢印をたどれます。 |
| フリーモードとDDDモードで、パン・ズーム後に選択と整列を行う | 描画上の境界で範囲選択でき、端・中央の揃え位置は表示倍率によらず一致します。 |
| 1枚、2枚、3枚を順に選ぶ | 枚数に応じて整列項目が有効になります。範囲選択中の `Esc` は、操作前の選択を保ちます。 |
| 反映前の入力を残したまま複数選択に切り替える | フォームの入力と選択が残り、反映または取り消しの案内が出ます。 |
| 同じ軸座標のカードを含める、空白幅が0または負になる、整列を続けて2回実行する | 同順位でも結果が一定です。空白幅が0なら配置し、負なら位置を保ちます。座標に実質的な差がない再実行の後も、その前の整列を取り消せます。 |
| 配置の一括更新に欠落したID、重複ID、または非有限の座標を含める | 更新はエラーになり、すべてのカードが元の位置に残ります。 |
| 整列後に取り消す。保存後の取り消しと、整列対象のドラッグ・削除後の取り消し可否も確認する | 戻せる場合は直前の配置に戻ります。他の編集が残る場合は未保存表示を保ちます。ドラッグや削除で配置が変わった対象を、古い履歴で上書きしません。 |
| `.lbproj` と `.sqlite` で整列し、保存・再オープンと JSON 書出を行う | 再オープンと書き出しで確定済みの座標を取得できます。保存に失敗した場合は、編集中の配置と未保存状態を保ちます。 |
